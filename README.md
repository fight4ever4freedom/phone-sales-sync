# 手机号售卖记录工具

这是一个本地网页 app，直接打开 `index.html` 就能用。数据保存在浏览器本地，可用右上角导出按钮备份 JSON，再用导入按钮恢复。

## 推荐流程

1. 先录手机号、卡情况、标签，例如“主”“蓝”“备用”。
2. 每个平台单独新增一条记录，不再把状态、金额、买家、日期、注销情况都塞进一个格子。
3. 状态只选固定项：已售、可售、封禁/异常、自用、注册/验证中。
4. 金额、买家、日期、备注分开填，后续统计收入和找库存会更快。
5. 每天结束导出一次 JSON 备份。

## 比石墨表更省事的地方

- 矩阵视图保留“手机号 × 平台”的习惯，点空格可快速补录。
- 明细视图适合查某个买家、金额、备注。
- 顶部自动统计手机号数量、平台记录、已售金额、可售库存、异常数量。
- 筛选平台和状态后，矩阵、明细、手机号列表会一起联动。
